# LocalHub

서울 공공데이터 기반 지역 정보 조회, 익명 커뮤니티, AI 챗봇을 제공하는 팀 프로젝트입니다.

## 기술 스택

- Frontend: Vue 3, Vite, Vue Router, Leaflet
- Backend: FastAPI, SQLAlchemy, SQLite, OpenAI API
- Deployment: Netlify, Render

## 로컬 실행 준비

1. `.env.example`을 `.env`로 복사하고 필요한 값을 입력합니다.
2. `backend`에서 Python 가상환경을 만든 뒤 `requirements.txt`를 설치합니다.
3. `frontend`에서 `npm install`을 실행합니다.

구체적인 실행법과 API 목록은 기능 구현과 함께 갱신합니다.
