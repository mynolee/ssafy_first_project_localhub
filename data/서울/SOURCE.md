# 데이터 출처 및 라이선스 — 서울 (SEL)

서울 지역정보는 한국관광공사 TourAPI와 서울 열린데이터광장의 두 출처를 함께 사용합니다.

## 출처별 수집 현황

| 제공 기관 | 데이터명 | 파일/건수 | 라이선스 |
| --- | --- | ---: | --- |
| 한국관광공사 | 국문 관광정보 서비스(TourAPI 4.0) | 7개 / 6,518건 | 공공누리 제3유형 |
| 서울특별시 | 서울시 일반음식점 인허가 정보(`LOCALDATA_072404`) | 1개 / 1,000건 | 공공누리 제1유형 |
| 합계 |  | 8개 / 7,518건 |  |

- TourAPI: https://www.data.go.kr/data/15101578/openapi.do
- 서울 일반음식점: https://data.seoul.go.kr/dataList/OA-16094/A/1/datasetView.do
- 수집일: 2026-07-16

`서울_음식점.json`은 영업상태코드가 `01`인 업소만 수집합니다. 2026-07-16 기준 전체 영업 중 업소는 120,343건이며, 지도와 API 응답 성능을 고려해 1,000건을 저장했습니다. 파일의 `totalAvailable`과 `truncated`에 전체 건수와 제한 수집 여부를 명시합니다. 이 데이터는 음식점 인허가 정보이며 서울시가 선정한 맛집 목록을 뜻하지 않습니다.

## 음식점 데이터 갱신

프로젝트 루트 `.env`의 `SEOUL_OPEN_DATA_API_KEY`에 발급 키를 설정한 뒤 실행합니다. 인증키는 JSON이나 Git 커밋에 저장하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-data.txt
Set-Location backend
..\.venv\Scripts\python.exe -m tools.collect_food_data seoul --max-items 1000
```

서울 API의 `X`, `Y`는 EPSG:5174 좌표이므로 수집 시 `pyproj`로 WGS84 경도·위도로 변환합니다.
