# 데이터 출처 및 라이선스 — 부산 (BSG)

부산 지역정보는 한국관광공사 TourAPI와 부산광역시 부산맛집정보 서비스의 두 출처를 함께 사용합니다.

## 출처별 수집 현황

| 제공 기관 | 데이터명 | 파일/건수 | 라이선스 |
| --- | --- | ---: | --- |
| 한국관광공사 | 국문 관광정보 서비스(TourAPI 4.0) | 7개 / 1,759건 | 공공누리 제3유형 |
| 부산광역시 | 부산맛집정보 서비스(`FoodService/getFoodKr`) | 1개 / 437건 | 이용허락범위 제한 없음 |
| 합계 |  | 8개 / 2,196건 |  |

- TourAPI: https://www.data.go.kr/data/15101578/openapi.do
- 부산맛집정보: https://www.data.go.kr/data/15063472/openapi.do
- API 엔드포인트: https://apis.data.go.kr/6260000/FoodService/getFoodKr
- 수집일: 2026-07-16

`부산_음식점.json`은 부산맛집정보 API가 제공한 437건 전체를 저장합니다. 음식점명, 주소, 전화번호, 좌표, 대표 이미지, 대표 메뉴와 운영 시간 등을 In지도 공통 형식으로 정규화했습니다.

## 음식점 데이터 갱신

프로젝트 루트 `.env`의 `BUSAN_FOOD_API_KEY`에 공공데이터포털에서 발급한 일반 인증키를 설정한 뒤 실행합니다. 포털에 표시되는 Encoding 또는 Decoding 키를 모두 사용할 수 있으며, 인증키는 JSON이나 Git 커밋에 저장하지 않습니다.

```powershell
Set-Location backend
..\.venv\Scripts\python.exe -m tools.collect_food_data busan
```
